# مانگا وەرگێڕ (Manga Live Translator) — Sorani Kurdish

## هەنگاوی ١: بنەمای پڕۆژە

ئەمە چی دەکات:
- بابلێکی شەمەندەفەر لەسەر هەموو ئەپەکان نیشان دەدات (دەکێشرێت)
- بە دەستلێدانی بابلەکە، «Continuous Mode» چالاک/ناچالاک دەبێت (سەوز = چالاک، خۆڵەمێشی = ناچالاک)
- لە کاتی چالاکبوون، شاشە دەگیرێت (≈ ٤ فرەیم/چرکە، نیوەی ڕێزولیوشن)
- ئاگادارکردنەوەیەکی چەسپاو هەیە بۆ وەستاندن

هێشتا وەرگێڕان نییە؛ ئەوە لە هەنگاوەکانی داهاتوودا دێت:
٢. ئاشکراکەری گۆڕانی پەڕە → ٣. OCR + دۆزینەوەی بابل → ٤. وەرگێڕان → ٥. نیشاندانی دەق

## بەکارهێنان
1. ئەپەکە بکەرەوە، «ڕێگەپێدانی پیشاندان» چالاک بکە
2. «دەستپێکردن» دابگرە و ڕێگەپێدانی گرتنی شاشە قبوڵ بکە
3. بچۆ ئەپی مانگاکەت، بابلەکە دابگرە

## تێبینی
- Android 14+: هەر جارێک دەبێت ڕێگەپێدانی گرتنی شاشە دووبارە بدرێت
- ئەپەکانی `FLAG_SECURE` وێنەی ڕەش دەدەن و ناگیرێن
- گۆڕینی ئاڕاستەی شاشە (rotate) هێشتا پشتگیری ناکرێت
